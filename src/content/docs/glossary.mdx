# Glossary

## Accuracy
How close a result is to the true or accepted value.

## Adjustment
Changing an instrument so its output better matches a reference.

## Calibration
Comparing an instrument or standard against a reference and documenting the relationship.

## Differential pressure
The difference between two pressure points.

## Gauge pressure
Pressure measured relative to atmospheric pressure.

## Precision
How closely repeated measurements agree with each other.

## Reference standard
A device or artifact used as the comparison point.

## TUR
Test uncertainty ratio; a way to compare tolerance to test uncertainty.

## Uncertainty
The doubt attached to a measurement result.
