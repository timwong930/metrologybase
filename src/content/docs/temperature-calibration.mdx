# Temperature calibration

Temperature calibration is less about a single number and more about controlling the whole measurement chain.

## Typical elements

- Sensor type and condition
- Reference standard or dry-block performance
- Immersion depth or probe placement
- Stability of the source
- Time for the system to settle

## Common mistakes

- Rushing the reading before the system stabilizes
- Ignoring thermal gradients
- Comparing sensors in very different mounting conditions
- Forgetting that contact quality changes the result

## Good habit

Treat temperature calibration like a system check, not just a device check. The setup often matters as much as the sensor.
